### 如何 rust 转 go

当前项目没有一行代码是 ai 主动写的，都是我手动复制的，在这个过程中我总结了一些经验：

1. 回归最初的网页版 ai 时代，而非现在的 ai agent 时代，才有助于进行知识的原始积累（不是舍弃 ai，而是不要让 ai 做，需要自己亲历亲为）
   * 这个过程中还能有助于更深入理解源码，能看到更多细节，**而不会一目十行，囫囵吞枣**
   * 这也可以归为阅读源代码的方法之一，但是应该只能是小项目吧，很快就能重写然后跑起来，不然大项目一直跑不起来...
     * 这么说来，挺适合教学式项目学习呢？
2. 任何不明白的地方，选中问 ai 即可

> 注意，这次 rust 转 go 只是一次练习，rust 项目我还是丢一边吧，专心 python 与 go
