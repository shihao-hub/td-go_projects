# console-calculator

控制台四则运算计算器，**手写词法分析 + 表达式求值**，不依赖任何第三方库。

## 支持

- 运算符 `+ - * / %`、括号嵌套、小数、一元正负号
- 运算优先级正确处理（先乘除后加减）
- 输入错误实时提示（非法字符、括号不匹配、除零等）
- 彩色面板输出算式与结果

## 用法

双击运行进入交互模式，输入表达式回车求值：

```
1 + 2 * 3       = 7
(1 + 2) * 3     = 9
10 / 4          = 2.5
-3 + 5          = 2
```

命令：`help` 查看帮助，`quit` / `exit` / `q` 退出。
